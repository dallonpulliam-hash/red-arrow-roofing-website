# Red Arrow Roofing website

A responsive static website starter for Red Arrow Roofing, LLC. Built with HTML, CSS, and vanilla JavaScript so it can be edited in Visual Studio Code without a framework.

## Files

- `index.html` — page content, sections, contact details, estimate form
- `styles.css` — responsive layout, colors, typography, and mobile styles
- `script.js` — mobile menu, customer review carousel, image lightbox, and estimate email form
- `images/` — project photos used in the roofing gallery

## Run locally

1. Extract the ZIP file.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the VS Code extension **Live Server** and choose **Open with Live Server**.

## Important before publishing

- The estimate form currently opens the visitor's email application and pre-fills an email to `scott@redarrowroofing.com`. It does not securely store or directly submit data. Connect a form backend/service (for example, Formspree, Netlify Forms, or a custom endpoint) for website-based submissions.
- The roofing gallery uses project photos from Red Arrow Roofing's Google Maps profile. Confirm permission for these and every other image before publishing; replace any image that is not cleared for use.
- Review all service descriptions, warranty/licensing wording, hours, service area, and testimonials with the business owner before launch.
- This starter uses Google Fonts and remote images, so those assets require an internet connection.
- Add a privacy policy and any required consent language if you add analytics, advertising pixels, or a hosted contact form.
- Do not represent Red Arrow Roofing as offering 24/7 emergency service. This draft reflects the current website's weekday work hours and weekend emergency inquiries.
